# NeCosmos v0.10

## 統合内容

Phase 3の猫8種の方向別画像、設置物32種類、地形6種類の完成GLB・定義と、Phase 4の凍結済み生態系・水文・土砂モデルを公開パッケージへ統合しました。実際の地表と水面は、現在のシミュレーション状態から更新します。

数値モデルは `f33fe9a232a05650`、基礎設定は `1965af03719d58ed` で固定しています。式・定数をJavaScriptの別モデルへ置き換えず、Pyodide 0.27.7 / NumPy 2.0.2で実行します。wasm32の配列添字に必要な型変換は接続部に分離しています。

## 限界と今後

- 猫による地形変化は1,200日でもサブミリ〜ミリ規模で、見た目の変化は小さい段階です。
- 魚ねこの長期存続は少なく、苔原の草ねこも厳しい結果です。ゲームバランスの完成を意味しません。
- 河川・池・侵食は簡略モデルであり、現実の水理・地質を予測するものではありません。
- 家具の足場・効果範囲メタデータを持ちますが、猫の登攀行動や環境家具の特殊効果は後続作業です。
- 初回に約20MB以上の計算・描画用ファイルを読み込みます。携帯端末の実機性能は別途評価が必要です。

## ブラウザ接続の確認

実際のブラウザで1,250日まで進め、16項目の統合テストに合格しました。既存河川の初期表示、300日観測、解放面積512セル、家具設置・足場座標・保護、セーブ復元と継続計算の一致、撤去後の保護解除、水・土砂・物質収支を確認しました。通常のお店操作による購入・設置、回転・ズーム、速度変更、一時停止、保存と再読み込みも確認しています。390px幅ではドキュメント幅も390pxで、横方向のはみ出しはありません。iOS実機性能は未検証です。

中央山プリセットはPhase 3の高さ操作を32×32セルに変換し、初期地形だけを傾斜緩和しています。ノイズ解像度の違いがあり完全な形状一致ではありません。360条件の本試験には含まれず、別途、湿潤・乾燥・苔原の各1,200日とブラウザでの生成・300日更新を確認しました。日次の物理・生態系更新式は共通です。

## 現在のゲーム内個体数上限

全8種を合わせて200匹です。通常繁殖・草ねこの自然発生・知恵ねこの出現すべてに適用します。枠に入らない出生は親のエネルギー・質量や土壌栄養を消費しません。既存セーブが200匹を超えている場合は猫を削除せず、200匹未満に減るまで新規増加を止めます。保存データにも現在の上限を適用します。

この制限は上記の長期評価を実行した後に追加したゲーム設定です。上記の試験結果は200匹制限なしの基準モデルの結果であり、200匹制限で再実行した結果ではありません。研究用途では上限を指定しない従来の更新も維持しています。
